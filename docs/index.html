工具 / 转换

书源转换

将开源阅读（Legado）书源转换为香色闺阁格式，支持 JSON 文件、订阅链接和批量导出。

开源阅读书源一键转换

粘贴或上传「开源阅读」书源 JSON（支持订阅链接、数组、单对象、{"0":{...}} 导出格式），转换为香色闺阁格式。 转换完全在本地浏览器完成；红色提示为需人工核对项。
修复版：enable 输出整数 1/0；权重至少为 1。取消勾选可保留 Legado 原始状态或原有效权重。

网站检测与自动修复

无需 API Key，即可检测搜索、详情、目录和正文，并查看字段样例与修改差异。检测会区分格式通过、网页验证及受限规则；自动修复候选经再次检测后供你确认，也可选择自己的 AI 进一步分析。

测试源的域名目前可能无法访问，真实结果以联网检测为准。
下载本次修复的两条书源 XBS 下载两条 JSON 查看柠檬小说不可达报告
网站检测会自动填写网络失败、字段匹配数量和 XPath 问题，无需人工输入。只有点击「使用我的 AI」才会向你配置的模型发送当前书源和证据；勿填写 Cookie 或私人凭据。
联网检测不需要 API Key。仅允许服务器审核过的公网书源域名，不会执行网页脚本、Cookie 或登录操作。

真实 HTTP / 网页解析检测

服务器读取网站搜索、详情、目录和正文的真实 HTTP 结果。

可以直接检测网站、自动修复并复测，无需 API Key。候选规则仍需香色闺阁 App 实测。

自动修复 / AI 修改建议

重要：联网检测会实际发送 HTTP 请求并解析静态 HTML；遇到超时、反爬或需要 WebView 的规则会显示受限，不代表 iOS App 已通过。修改仍需你手动确认。

帮助 / 说明

使用说明

从导入书源到导出 XBS，快速了解工具的使用方式和常见注意事项。

快速上手

  1. 准备书源

    从开源阅读导出 JSON 文件，或复制书源订阅链接。

  2. 转换书源

    进入「书源转换」上传文件或粘贴 JSON，点击开始转换。可选择全部启用与权重。

  3. 导出并导入

    转换完成后下载 XBS，使用香色闺阁导入。若网页端提示规则需人工核对，请先确认对应站点。

常见问题

说明与常见问题
· 转换引擎与本仓库 converter/ 完全同源（converter.bundle.js），App 内置的也是同一份。
· 「需人工处理」提示来自规则级诊断：无法翻译的语法会保留原样并标红，导入 App 后可手动微调。
· XBS 文件 = XXTEA 加密的 JSON（末尾 4 字节小端存放原始长度），本页加解密与官方格式字节兼容。
· 本工具仅供学习交流，请勿用于商业用途。

    AI 模型设置

    自定义 API Key / 接口地址，无订阅账号、无需 OAuth

    你的配置只属于当前浏览器。API 地址、API Key、模型与参数只保存在当前浏览器的 localStorage，不同用户、不同浏览器之间不共享；服务器不保存到数据库、磁盘文件或访问日志。
    点击「读取模型」「测试连接」「AI 修复」时，Key 会随本次请求临时经过 Node.js 服务端转发至你选择的 AI 提供商；服务端不会保留 Key。可点击下方「清除本地配置」或清除浏览器网站数据删除设置。
    安全提醒：当前公网页面使用 HTTP，浏览器发送的 API Key 没有 HTTPS 传输保护。不要在不可信网络中发送真实 Key；担心隐私请自己通过 Docker 部署并使用 HTTPS。浏览器扩展与具有本站脚本权限的代码也可能访问 localStorage。
    OpenRouter、DeepSeek、GLM、Qwen、Ollama 等兼容服务可选 OpenAI 兼容。Gemini 原生接口仅支持 Google 官方域名。
    填写 API 根地址，通常以 /v1 结尾，不要带 /chat/completions 或完整请求路径。共享服务仅允许公网 HTTPS 地址。
    Key 仅写入本浏览器 localStorage；服务端不提供公共 API Key。
    推荐 8192；可按需设至 262144（256K）。最大输出仅是允许的上限，并不要求模型生成这么多。实际以所选模型支持为准；1M 上下文不等于输出上限。
