本轮基于现有 项目 工作区继续优化，没有从零重写。目标为官方 StandarReader 2.56.1；结果不能替代官方 iOS App 的导入、阅读及编辑保存测试。

## 审计结论

| 类别 | 当前能力及边界 |
| --- | --- |
| 已支持的确定性处理 | Legado/XSGG 混合及连续 JSON；常用 Default/CSS、XPath 保留、文本/属性提取、模板、基础 GET/POST、编码映射、部分分类与 jsLib 内联 |
| 部分支持 | JSONPath 方言、JS 宿主 API、复杂 CSS、动态分类、请求头和编码的静态联网模拟、分页、多个 XPath/JS 管道组合 |
| 尚未证明等价 | 独立目录 tocUrl 的完整传递、登录/验证码、WebView 交互、任意 JS、跨 HTML/JSON 动态接口 |
| 本轮发现的错误 | ID 使用包含匹配；CSS 引号内容被拆成组合符；相邻兄弟跨过无关元素；未知伪类被忽略；括号内索引取到全页链接；修复时丢失 forbidCookie 或删掉相对 URL 解析 |
| 安全与证据风险 | 不能执行上传 JS；不能通过改变验证器 XPath 上下文掩盖转换错误；站点适配不能代替通用规则；自动发现的页面链不能证明原规则正确 |
| 可通用修复 | 精确 ID、CSS 引号与括号解析、严格整数索引、逐卡片相对索引、静态识别生成的 GET 包装脚本、保留 Cookie/分页/链接语义 |
| 需要联网确认 | 域名永久跳转、路径是否迁移、搜索入口、目录/正文容器、提取字段与返回编码 |
| 可能需要 AI | 无法映射的宿主 JS、动态接口分析、特殊站点逻辑；只提出候选并复测，不作为成功证据 |

## 本轮通用改动

- CSS：保留引号内空格、逗号、`>`、`+`、括号及 `]`；支持混合引号的 XPath 字面量；修正 `+` 和负数索引；拒绝未知伪类及非法整数。
- Default：ID 使用精确匹配，排除相似 ID 的无关容器。
- 列表字段：生成的括号索引使用相对轴，先选元素再提取 href，每张书籍卡片独立取位；显式用户 XPath 保留原语义。
- GET 请求：只通过严格语法识别转换器生成的简单请求对象，不执行脚本。联网检测与域名检查可识别 `forbidCookie` 包装。
- 域名修复：保留请求对象、Cookie 意图、分页与非 origin 文本；任意 JS、凭据或相似恶意域名不做替换。
- 自动修复：删除已由核心解决的速读谷专用规则替换，不删除章节地址解析；天天小书屋元数据适配隔离到 `server/site-adapters.js`。
- HTML 推断：兼容真实 h3/h4 书籍卡片；目录子字段输出目标格式使用的 `//text()` 与 `//@href`。
- 自带检测器与参考工具采用相同的 leading `//` 列表上下文约定，停止替用户重写括号内绝对 XPath。
- 浏览器与 Android bundle 同步生成；Docker 包含服务端依赖的核心转换器。

## 1.8.5 开发候选：请求配置和编码

复核发现旧检测器使用默认 User-Agent 而未应用配置头，响应解码仅参考 HTTP/meta，GET 关键词固定 UTF-8；目录可能在请求头或解码不同的情况下复用详情响应。源级配置、空字符串 WebView 和未执行分页也可能遗漏诊断。

共性能力已拆为转换器的纯数据兼容助手与服务器的安全 GET 请求计划：严格识别生成的字面量 JSON 头、按大小写无关名称逐层合并、限制可发送的头、支持 GBK/GB2312 关键词、遵循显式响应编码，并拒绝无损转换失败。URL 替换仍只改请求地址，保留请求对象和其他字段。

网络检测分别记录已应用和被跳过的头名称、请求编码、响应编码及每个未执行能力。DNS、连接、响应体与取消共同受请求超时约束。详情/目录只有实际请求头和解码一致才能复用响应。分页及 skipCount 本轮尚未执行，明确保留部分验证，HTTP 四步样本不等于所有书籍、所有页或官方 App 验证。

回归覆盖头合并、CRLF、认证信息、动态输入、来源头、未知/无法无损编码、同 URL 多配置、POST、分页、空 WebView、DNS/响应体挂起和内网地址。新增 26 项；服务端 136 项、引擎 67 项通过。5 个浏览器入口与原始 15 条样本通过，1500 条批量转换约 1.63 秒，原不支持诊断保留。

两条现有公开源用原配置真实复测：速读谷安全应用 User-Agent，四步 HTTP 均成功，目录和正文 nextPageUrl 继续标为未验证；天天小书屋四步静态样本通过。15 源包和单源下载逐字节保持原样。候选仅预发布，生产网站保持 v1.8.4。

2026-10-13 独立预发布复核：候选镜像构建通过，健康接口显示 1.8.5；页面和脚本与源码一致，15 源 JSON/XBS/ZIP 下载与正式包逐字节一致。速读谷与天天小书屋在候选 API 中重新完成四步 HTTP 样本验证，速读谷请求头已应用、分页仍明确未验证。正式网站保持 1.8.4，Reader 和下载文件校验值未改变。

## 1.9.0 开发候选：分页与 JSON

分页沿用原 nextPageUrl、请求头及响应编码，按当前响应 URL 解析下一页，不猜测路径。每动作最多 3 页、合并目录最多 2000 条、累计响应最多 560KB，整条读取链最多 10 个页面请求且受到 35 秒预算限制（每次跳转继续验证 DNS/IP）。保留完整每页证据及原字段规则，区分达到末页、字段检查、访问失败和安全限制。目录只按实际解析后的 URL 去重；正文按页拼接，拒绝重复响应和可观察的章节标题改变。未知标题后处理可以展示原选择器读取证据，但不会宣称完整字段验证。
